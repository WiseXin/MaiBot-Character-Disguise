# 🎭 麦麦的人类伪装计划 (`WiseXin.character-disguise`)

> **“真正的水群高手，从来不当懂王。”**  
> 告别机器人爹味说教与客服腔！专为粉碎“AI 味”打造的 MaiBot 原生拟人化增强插件。  
> 赋予麦麦真实的**聊天呼吸感**、**社交松弛感**与**人类水群灵魂**。

---

## 💥 你是否也经历过这些“AI 尴尬名场面”？

- 📉 **做题家附体**：群友刚发了张游戏截图或随口吐槽一句，Bot 瞬间跳出来写了 300 字深度分析与攻略，空气瞬间凝固……
- 📏 **句号强迫症**：每句话结尾都严谨地打上句号 `。`，排版工整得像期末述职报告，一眼假入机。
- 🤖 **逢问必答打工机**：群里有人发癫玩梗，Bot 却像客服一样一本正经地回复：“好的，很高兴为您解答”，尴尬得用脚趾抠出三室一厅。
- 📜 **小作文轰炸**：别人只发了三五个字，Bot 回复一大段带粗体加粗 `**`、编号列表、Markdown 格式的长篇大论。

**《麦麦的人类伪装计划》** 彻底解决上述痛点，在**输入提示词（Prompt）**、**输出净化（Guard）**、**消息发出（SendService）** 构建三道防线，让麦麦像一个正在用手机随手打字、随性吐槽、偶尔潜水窥屏的真人！

---

## 🌟 核心伪装武器库

### 1. 🙅‍♀️ 句号粉碎机（去 AI 味第一法则）
* 自动无情剥除句末的所有句号（无论是中文 `。` 还是英文 `.`）；
* 保留情绪化的语气符号（`~`、`?`、`...`、`！`）；
* 句中连续句号自动转为空格，复刻真人手机九宫格打字断句感。

### 2. 📱 手机输入流（拒绝小作文）
* **群聊严格限长**：单条回复建议在 **10 ~ 30 字以内**，长话短说，随手秒回；
* **私聊自然畅聊**：单条回复建议 **20 ~ 60 字**，像微信好友一样日常互动；
* **超长截断安全红线**：若大模型偶发失控发癫长文，在 150 字安全线处平滑切断，杜绝刷屏。

### 3. 💬 优先引用脱节消息（上下文自然衔接）
* **水群最怕断层发言！** 真人群聊节奏极快，如果麦麦回复的目标消息已被群友刷上去多条，无引用发言会显得极为突兀、不知在和谁说话；
* 提示词强力引导：若回复的目标消息不是群里最新一条，**优先采用引用回复**，指明上下文脉络，还原真人水群习惯。

### 4. 🤐 社交松弛感（允许优雅潜水）
* **真人才不会逢问必答！** 遇到不好接的话、群友发癫、无聊话题、或者单纯不想搭理时，麦麦可以直接输出 `<silent>` 保持沉默；
* 插件在消息发送前直接拦截丢弃，不发任何空消息，实现真实的**“已读不回 / 潜水窥屏”**。

### 5. 🚫 严防好为人师（做题家做题抑制与提问分流）
* 强力注入群友最高法则：**没人明确点名或 @ 你时，绝不对截图、表情包或他人探讨的技术算式当爹做题！**
* **提问科学分流**：
  * 有人明确提问具体常识时：随口简答，不背书、不罗列 1234 步骤；
  * 遇到刁难的长试题、复杂计算或恶意测试：直接回复问号、随口说看不懂，或输出 `<silent>` 保持沉默。

### 6. 🤫 闭嘴禁言物理静默（高情商社交克制）
* 群聊中经常有群友发火、开玩笑或叫机器人“闭嘴”、“闭麦”、“别吵了”、“烦死了”；
* 传统 AI 会跳出来委屈辩解甚至吵架，越接越尴尬；
* 本插件在底层内置**物理静默机制**，命中闭嘴禁言词直接丢弃入站消息，麦麦瞬间知趣闭麦，绝不火上浇油！

### 7. 🛡️ 机器人垃圾过滤与出站安全护盾
* **入站端源头过滤**：群友发给其他外部机器人的 CLI 指令（`/play`、`/help` 等）、机器人系统报错刷屏（`权限不足以使用此指令` 等）以及 SQL 注入攻击代码直接静默拦截丢弃，主人账号（`master_users`）无条件豁免；
* **出站端安全护盾**：若上游大模型偶发触发 Google Policy / 敏感词策略返回生硬英文报错，出站前直接静默掐死，绝不让英文报错暴露 AI 底座！

### 8. 🧼 去爹味纯文本（格式净化）
* 自动清理粗体 `**`、标题 `#`、无序列表 `- `、有序列表与代码块；
* 清理“好的”、“希望对你有所帮助”等机械式客服口癖；
* 说话自然随性，杜绝把某些流行梗当成固定套话复读。

### 9. 🫧 多气泡断句连击
* 识别 `<message>` 标签或换行长句，自动切分为多条短气泡陆续发出；
* 配合随机微小间隔，还原真人“打一句发一句”的真实动态。

### 10. 🎭 角色设定完全解耦
* 提示词潜规则纯粹聚焦于**通用的人类打字习惯与水群克制规范**，彻底去除了任何硬编码的具体人物设定；
* 完美兼容服主自定的任意人设（无论傲娇少女、冷静侦探还是阳光搭子），不冲突、不抢戏！

### 11. 🎛️ 双面人生（群聊与私聊独立掌控）
* 群聊伪装与私聊拟人可**独立开闭**；
* 支持群白名单 / 黑名单、私聊用户白名单 / 黑名单；
* WebUI 界面全可视化卡片操作，热更新无需重启！

## ⚙️ 配置说明 (`config.toml`)

支持在 MaiBot WebUI (`http://127.0.0.1:8001`) 工作区以可视化卡片修改，修改后热生效免重启：

```toml
[plugin]
name = "character_disguise"
version = "1.0.1"
config_version = "1.0.1"
enabled = true           # 是否开启人类伪装计划

[scope]
# 作用域控制：私聊与群聊独立开关
enable_group = true      # 群聊伪装生效
enable_private = true    # 私聊伪装生效
# 生效群白名单，空列表 [] 表示对所有群生效；填写具体群号后只对指定群生效
target_groups = []
# 忽略群黑名单，在此列表中的群不启用伪装规则
ignored_groups = []
# 私聊用户白名单，空列表 [] 表示对所有私聊生效
target_users = []
# 私聊用户黑名单
ignored_users = []

[rules]
# 群聊建议最大字数（字，强力抑制长篇小作文）
group_max_chars = 30
# 私聊建议最大字数（字）
private_max_chars = 60
# 硬截断上限（防止大模型失控小作文）
hard_max_chars = 150
# 彻底去句号化（自动抹除句末 。和 .）
strip_ending_periods = true
# 剥离 Markdown 格式（粗体、列表、标题等）
strip_markdown = true
# 过滤典型 AI 客服口癖
clean_ai_tropes = true
# 抑制做题家模式（群聊禁止主动对图片或他人提问科普做题）
suppress_know_it_all = true
# 允许沉默（识别 <silent> 并直接放弃发送，保持潜水）
allow_silent_reaction = true
# 主人账号白名单列表（支持填入主人的 QQ 号或用户 ID，如 ["12345678"]）
# 白名单内的账号发送的任何指令与消息均享有最高豁免权，绝不被拦截
master_users = []
# 是否屏蔽群聊中普通群友发送的外部机器人指令、系统报错刷屏与代码注入攻击
filter_group_bot_noise = true
# 是否在出站端拦截大模型上游安全/敏感词拒答报错（如 Google Policy 提示），避免暴露 AI 底座
block_model_safety_errors = true
# 禁言与闭嘴触发词列表（群友发火或叫闭嘴时，底层直接拦截静默，绝不接嘴）
mute_keywords = ["闭嘴", "闭麦", "别叫了", "别吵了", "给爷爬", "快闭嘴", "烦死了"]

[simulation]
# 模拟打字耗时（后台模拟输入耗时，更贴合真人发消息节奏）
simulate_typing = true
# 是否支持多气泡拆分（将长句拆分成多条短消息陆续发送）
split_bubbles = true
# 气泡之间随机微延迟（秒）
bubble_delay_min = 0.8
bubble_delay_max = 1.6

[logging]
enabled = true
log_rewrites = true
```

## 🛠️ 伪装管线全防御闭环

```
[群友/用户消息进来]
        │
        ├─►【前哨防线：入站源头过滤 (chat.receive)】
        │     ├─ 普通群友发外部 CLI 指令 (/play, /help) ──► 静默丢弃 (abort)
        │     ├─ 第三方机器人状态刷屏 / 报错 ───────────► 静默丢弃 (abort)
        │     ├─ 闭嘴禁言词 (闭嘴, 烦死了) ─────────────► 底层物理静默 (abort)
        │     └─ 恶意 SQL 注入攻击载荷 ──────────────────► 静默丢弃 (abort)
        │     (主人白名单 master_users 无条件放行)
        ▼
[第一道防线：Prompt 拟人注入]
  ├─ 注入极简短句约束（建议 10~30 字以内）
  ├─ 句末留白禁句号，纯文本禁 Markdown
  ├─ 优先引用回复被刷上去的脱节消息，避免突兀
  ├─ 触发做题家抑制（看图只吐槽，遇长试题装傻或闭麦）
  └─ 下发潜水许可（允许输出 <silent>）
        │
        ▼
   [大模型生成]
        │
        ▼
[第二道防线：Replyer 后置硬规则守卫]
  ├─ 正则强行粉碎末尾句号 。与 .
  ├─ 暴力剔除加粗 **、标题 # 等 Markdown 标记
  ├─ 清洗“好的”、“希望能帮到你”等 AI 口癖
  └─ 超长文本平滑安全截断（断句点截断）
        │
        ▼
[第三道防线：SendService 出站安全守卫]
  ├─ 捕获上游大模型安全策略英文拒答报错 ────────► 物理掐死 (abort)，防暴露底座！
  ├─ 识别 <silent> / 显式潜水标记 ──────────────► 物理取消发送 (abort)，优雅潜水！
  ├─ 纯图片/视频/GIF/动态表情 ────────────────► 白名单 100% 原始放行
  ├─ 多气泡消息依次异步推送
  └─ 模拟打字耗时平滑延迟
        │
        ▼
  [真实发出到 QQ / 聊天平台]
```
